# AquaPixel Sanctuary

Web mô phỏng hệ sinh thái thủy sinh pixel-art bằng HTML/CSS/JavaScript thuần.

## Chạy ngay
- Mở `index.html` bằng trình duyệt hiện đại.
- Hoặc upload toàn bộ thư mục lên GitHub Pages.

## Cơ chế mô phỏng
- Oxy / CO2 theo hô hấp, quang hợp và sủi khí.
- Amoniac từ sinh vật, thức ăn thừa và phân hủy.
- Chu trình vi khuẩn chuyển amoniac thành nitrat phụ thuộc oxy.
- Cây/tảo hấp thụ nitrat và sinh oxy khi có ánh sáng.
- Nhiệt độ theo ngày/đêm, đèn và máy sưởi.
- Cá có đói, năng lượng, stress, chết và sinh sản khi điều kiện phù hợp.
- Tép/ốc dọn thức ăn, chất thải và tảo.
- Tốc độ x1/x3/x8, lưu hồ bằng localStorage.

Lưu ý: đây là mô phỏng gameplay có cảm hứng sinh thái học, không phải công cụ khoa học hoặc hướng dẫn chăm cá ngoài đời.
