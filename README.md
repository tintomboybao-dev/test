# AquaPixel Sanctuary V2

Một web game pixel-art mô phỏng hệ sinh thái thủy sinh, chạy hoàn toàn bằng HTML/CSS/JavaScript thuần.

## Chạy

- Giải nén thư mục.
- Mở `index.html` trực tiếp bằng Chrome/Edge/Firefox, hoặc upload toàn bộ thư mục lên GitHub Pages.
- Không cần npm, build, server hay PWA.

## V2 có gì mới

- Mỗi con cá có tên, giới tính, tuổi, tính cách, tâm trạng, sức khỏe, đói, năng lượng và quan hệ.
- Cá có gene màu + hoa văn, sinh sản bằng trứng, truyền gene và có xác suất đột biến hiếm.
- Aquadex để sưu tập loài, cây và đột biến.
- Chu kỳ ngày/đêm ảnh hưởng hành vi và quang hợp.
- Random event: nắng nóng, mưa lạnh, algae bloom, ấu trùng muỗi, mystery seed và khách hiếm.
- Môi trường thay đổi theo vị trí: O2, NH3, nhiệt độ, ánh sáng và dòng nước.
- Bộ Test nước có overlay theo vùng.
- Máy lọc tạo dòng nước, cuốn thức ăn/chất thải và hỗ trợ xử lý độc tố.
- Cây tăng chiều cao, phân nhánh và lan ra khi điều kiện tốt.
- Tép và ốc hoạt động rõ hơn về đêm.
- Lưu hồ bằng localStorage; tự lưu định kỳ.

## Điều khiển

- Click lên cá: mở hồ sơ cá thể.
- Click vào hồ: đặt vật thể đã chọn.
- Giữ chuột: rải liên tục.
- Chuột phải: xóa gần vị trí trỏ.
- Phím 1-0, Q/R/W/E/X: chọn nhanh công cụ.
