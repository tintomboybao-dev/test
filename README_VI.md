# SIGNAL // 47 — BẢN HOÀN CHỈNH TIẾNG VIỆT

Mở trực tiếp `index.html` bằng Chrome hoặc Edge để chơi. Không cần cài đặt, không cần npm, không cần máy chủ.

Bản này đã được Việt hóa toàn bộ phần hiển thị: giao diện, chiến dịch, tín hiệu, nghiên cứu, ECHO, trang bị, trạm K-47, CCTV, tàu thăm dò, nhật ký, thành tựu và các kết thúc.

## Điều khiển nhanh
- Xoay núm bằng chuột quanh tâm núm, lăn chuột hoặc nhập trực tiếp MHz.
- `TỰ ĐỘNG DÒ` để tìm tín hiệu mới.
- `GIẢI MÃ` để mở nội dung tín hiệu.
- `ĐI TRONG K-47`: dùng WASD/phím mũi tên, nhấn `E` để tương tác.
- Terminal hỗ trợ cả lệnh cũ và bí danh tiếng Việt. Gõ `trogiup` để xem danh sách.

Save vẫn dùng `localStorage` với khóa `signal47` và tiếp tục tương thích với save cũ.
